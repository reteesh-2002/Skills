# Anti-Slop Spec

Transforms lazy, generic AI prompts into uncompromising, culturally grounded, high-craft specifications. Prevents the AI median aesthetic (the standard dark-mode SaaS dashboard with rounded cards, cyan/purple glows, and Inter font) from ever being generated.

## The AI Slop Banned List

When formulating an Anti-Slop Spec, actively ban and replace these 6 lazy AI defaults:

| # | Banned AI Default | Why It's Slop | The High-Craft Replacement |
| :- | :--- | :--- | :--- |
| 1 | **Dark `#0d0f12` + soft border `#252a34`** | Every single AI tool defaults to this exact SaaS dark theme. | Anchored color systems: Warm parchment, brutalist monochrome, deep oxblood, or industrial matte slate. |
| 2 | **Rounded cards (`border-radius: 8-12px`)** | Cookie-cutter card grids found in every template marketplace. | Sharp tabular ledgers (`0px` or `2px`), physical chassis, or asymmetric editorial layouts. |
| 3 | **Pill tags (`#cyan`, `#purple`)** | Lazy categorization badges that make every app look like an issue tracker. | Monospace stamp codes (`[DEPT-01]`), engraved metadata, or structural section dividers. |
| 4 | **Inter / Roboto / System Sans-serif** | Bland typographic neutrality with zero personality. | Intentional pairings: Expressive Display Serif + Monospace accent, or Industrial Grotesque + Technical Sans. |
| 5 | **Soft float hover scaling (`scale(1.02)`)** | Cheap transition with zero physical tactile sensation. | Physical click depth (`translateY(2px)` with shadow collapse), mechanical toggle snaps, or instant active states. |
| 6 | **Generic 3-Column Grid** | Default flex/grid layout applied blindly to products, notes, and team members. | Contextual visual architecture: Tasting ledgers, telemetry HUDs, command terminals, or split-screen broadsheets. |

## The 4-Pillar Spec Refinement Engine

When activated with an idea or raw prompt:

### Pillar 1: Cultural & Domain Anchoring
Root the application in its authentic physical or professional world, selecting one matching archetype from the **`frontend-artisan` 10 Archetypes Canon** (e.g. *01-Terminal Density*, *04-Hardware Skeuomorphic*, *08-Neo-Brutalist*, *10-Kinetic Dark*):
- A biryani restaurant is not a SaaS app: it has brass degs, saffron embers, parchment dispatch slips, and dum seals.
- A developer tool is not an e-commerce store: it has high-density data matrices, stream buffers, and terminal keys.
- An audio synthesizer is not a blog: it has brushed metal knobs, rotary pots, LED segment readouts, and patch cords.

### Pillar 2: Explicit Typography System
Specify exact font families, weights, and roles using accessible web fonts (Google Fonts or native system stacks):
- **Display / Hero**: Sets the soul and tone (e.g., `Playfair Display`, `Syne`, `Space Grotesk`, `Cinzel`, `Cabinet Grotesk`).
- **Body / Content**: High readability, generous line height, strict tracking.
- **Data / Microcopy**: Monospace (`JetBrains Mono`, `Space Mono`, `DM Mono`) for numbers, timestamps, IDs, and controls.

### Pillar 3: Signature Tactile Interaction
Every Anti-Slop Spec MUST define at least **one bespoke, non-standard interaction** that could never appear in a generic template:
- A live calculation slider that recalculates physical portions or hardware units.
- A physical perforated receipt tape (Kitchen Order Ticket) with tear marks instead of a slide-out drawer.
- A physical rotary dial with audio click feedback via the Web Audio API.
- A keyboard-driven command palette or interactive node-canvas.

### Pillar 4: Exact Banned Directives
Embed explicit negative constraints directly into the generated prompt:
- *"Do NOT use purple gradients, cyan glow pills, or rounded gray card grids."*
- *"Use strict 0px border-radius with 1px solid hairline borders."*

## Output Deliverables

When invoked, generate:
1. **The Anti-Slop Analysis**: 3 bullet points explaining why the default prompt would have generated generic slop.
2. **The High-Craft Direction**: Palette hex codes, typography pairings, and layout metaphor.
3. **The Executable Copy-Paste Prompt**: A self-contained, battle-tested prompt ready to send to any AI model to generate the complete code without falling into the template trap.
